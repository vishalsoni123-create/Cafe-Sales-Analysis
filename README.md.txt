# Cafe Sales Analysis Dashboard

## Project Overview
This project analyzes cafe sales data using Microsoft Power BI. The dashboard presents key sales metrics and visualizations to help understand sales performance across products, payment methods, and store locations.

## Objectives
- Analyze overall sales performance.
- Track total spending, quantity sold, and number of transactions.
- Compare sales across products and payment methods.
- Understand sales distribution by store location.
- Visualize monthly sales trends.

## Tools and Technologies
- Microsoft Power BI
- Power Query for data cleaning and transformation
- DAX for calculated measures (where applicable)
- Data visualization

## Data Cleaning
The dataset was cleaned and transformed using Power Query in Power BI. Data preparation steps were applied to make the data suitable for analysis.

## Dashboard Features
- **Total Spent:** Tracks total sales value.
- **Total Quantity:** Shows the total quantity sold.
- **Total Transactions:** Displays the number of transactions.
- **Payment Method Analysis:** Compares payment methods.
- **Sales by Product:** Shows sales distribution across products.
- **Location Analysis:** Compares sales by store location.
- **Monthly Sales Trend:** Visualizes sales changes over time.
- **Month Slicer:** Allows users to filter the dashboard by month.

## Key Insights
The dashboard can be used to identify sales patterns, compare product performance, examine payment preferences, and explore differences across locations and months.
